## หน้าที่ใช้ตรวจสอบ

1. `/admin/grade-reviews` — รายการตรวจสอบและประวัติ workflow
2. `/admin/grade-reviews/grade/ประถมศึกษาปีที่%201` — รายวิชาระดับชั้น
3. `/admin/grade-results` — ผลการเรียนที่ผ่านการตรวจสอบแล้ว
4. `/admin/grade-results/de000000-0000-4000-8000-000000000140` — รายละเอียดและ PDF ปพ.5
5. `/admin/documents/pp5` — เมนูเอกสาร ปพ.5

ข้อมูลตัวอย่างมีนักเรียน 8 คน คะแนน 5 หมวด ผล `ร`, `มส`, `มผ`
ผลประเมินคุณลักษณะ การอ่านคิดวิเคราะห์และเขียน กิจกรรมพัฒนาผู้เรียน
และประวัติ `ส่งตรวจ → ส่งกลับแก้ไข → ส่งใหม่ → ตรวจแล้ว → อนุมัติ → ปิดผลการเรียน`
