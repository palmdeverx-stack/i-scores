# การส่งอีเมลของระบบโรงเรียน E-KRU

ระบบโรงเรียนรองรับ Gmail SMTP แบบเดียวกับ E-KRU Marketplace และรองรับ Resend ผ่านการตั้งค่า `EMAIL_PROVIDER` ตรวจผู้ให้บริการและที่อยู่ผู้ส่งได้ที่ `/master/email-settings`

## Gmail SMTP

ตั้งค่าฝั่งเซิร์ฟเวอร์ใน `.env.local` สำหรับ dev หรือใน Environment Variables ของ deployment สำหรับ production

```env
EMAIL_PROVIDER=gmail
GMAIL_USER=sender@gmail.com
GMAIL_APP_PASSWORD=<Google App Password>
```

- `GMAIL_USER` คือบัญชี Gmail ที่ใช้ส่ง ระบบใช้บัญชีนี้เป็นผู้ส่งโดยอัตโนมัติ
- `GMAIL_APP_PASSWORD` คือรหัสผ่านแอปจากบัญชี Google ที่เปิดยืนยันตัวตนสองขั้นตอน เก็บเป็น secret ฝั่งเซิร์ฟเวอร์
- การเชื่อมต่อใช้ `smtp.gmail.com` พอร์ต `465` ผ่าน TLS หลังตั้งค่าให้เริ่ม dev server ใหม่หรือ redeploy ใน environment ที่แก้
- บัญชี Gmail ส่วนตัวไม่มีค่า SMTP เพิ่ม และมีเพดานส่งโดยทั่วไป 500 อีเมลต่อวัน ถ้าระบบโรงเรียนกับ Marketplace ส่งจากบัญชีเดียวกัน การส่งจะนับรวมในบัญชีนั้น [ข้อจำกัดของ Gmail](https://support.google.com/mail/answer/22839?hl=th)

## Resend

กำหนด `EMAIL_PROVIDER=resend` หรือใช้ค่าเริ่มต้น แล้วตั้ง `RESEND_API_KEY` ไว้บนเซิร์ฟเวอร์ ระบบอ่านอีเมลผู้ส่งจาก `/master/email-settings` ซึ่งบันทึกใน `system_email_settings.resend_from_email` และใช้ `RESEND_FROM_EMAIL` เป็นค่าสำรอง ผู้ส่งต้องอยู่บนโดเมนที่ยืนยันกับ Resend แล้ว ส่วนอีเมลผู้รับใช้ Gmail ได้

ตั้ง `RESEND_USAGE_API_KEY` แบบ Full access แยกได้หากต้องการดูโควตา ถ้าอ่านโควตาแล้วได้ `401 restricted_api_key` ให้ตรวจสิทธิ์คีย์อ่าน เพราะคีย์ที่มีสิทธิ์ส่งอย่างเดียวอ่านโควตาไม่ได้ [สิทธิ์คีย์ Resend](https://resend.com/changelog/new-api-key-permissions)

## คำเชิญผู้ดูแลโรงเรียน

| การทำงาน | อีเมลผู้รับและข้อมูลที่ส่ง |
| --- | --- |
| สร้างโรงเรียนที่ `/master/school/new` | ส่งไปที่อีเมลรับคำเชิญของโรงเรียน หลังสร้างบัญชีผู้ดูแลสำเร็จ ส่งชื่อผู้ใช้ รหัสผ่านชั่วคราว PIN โรงเรียน และลิงก์เข้าสู่ระบบ |
| กดบันทึกในหน้าแก้ไขโรงเรียน | บันทึกการเปลี่ยนแปลงอย่างเดียว |
| ส่งคำเชิญอีกครั้งจากหน้าแก้ไขโรงเรียน โดยเว้นรหัสผ่านว่าง | ส่งไปที่อีเมลรับคำเชิญของโรงเรียน ผู้รับใช้รหัสผ่านปัจจุบันของบัญชี |
| ส่งคำเชิญอีกครั้งจากหน้าแก้ไขผู้ดูแล | ส่งไปที่อีเมลในโปรไฟล์ผู้ดูแลที่เลือก ผู้รับใช้รหัสผ่านปัจจุบันของบัญชี |
| ตั้งรหัสผ่านชั่วคราวและส่งจากหน้าแก้ไขโรงเรียน | ใช้ได้กับบัญชีที่ยังรอเปลี่ยนรหัสผ่านครั้งแรกและผ่านการตรวจว่าเป็นบัญชีเฉพาะ ส่งรหัสใหม่ไปที่อีเมลของบัญชีผู้ดูแล |

อีเมลรับคำเชิญของโรงเรียนกับอีเมลโปรไฟล์ผู้ดูแลเก็บคนละช่องและอาจต่างกันได้ บัญชีเดียวมีรหัสผ่านปัจจุบันชุดเดียว หากตั้งรหัสใหม่สำเร็จแต่ส่งอีเมลไม่สำเร็จ รหัสใหม่มีผลแล้วและหน้าจอจะแจ้งให้ทราบ

ปุ่ม **พรีวิวอีเมล** แสดงเทมเพลตพร้อมข้อมูลตัวอย่าง เทมเพลตอีเมลเชิญใช้ LINE Seed Sans TH และมีฟอนต์สำรองสำหรับโปรแกรมอีเมลที่โหลดเว็บฟอนต์ไม่ได้

## เมื่อตรวจว่าอีเมลไม่เข้า

1. เปิด `/master/email-settings` ตรวจผู้ให้บริการและบัญชีผู้ส่งของ environment ที่กำลังใช้งาน
2. ตรวจที่อยู่ผู้รับในหน้าต่างยืนยันก่อนกดส่ง การบันทึกฟอร์มกับการส่งคำเชิญเป็นคนละคำสั่ง
3. ถ้าผู้ให้บริการรับคำขอแล้ว ให้ตรวจโฟลเดอร์ Spam ของผู้รับ และตรวจ Gmail Sent หรือ Resend Email Logs ตามผู้ให้บริการ
4. หากใช้ Gmail SMTP แล้วขึ้นข้อผิดพลาดยืนยันตัวตน ให้ตรวจบัญชีและ App Password การทดสอบ SMTP ด้วย `transport.verify()` ตรวจการเชื่อมต่อและการยืนยันตัวตน

จุดอ้างอิงในโค้ดอยู่ที่ `src/lib/gmail-email.ts`, `src/lib/resend.ts`, `src/lib/school-invite-email.ts` และ `src/app/api/schools/[id]/resend-invite/route.ts`
